課本重點

LF01

Topic：時間直接讀數法

Rule：非整點時間採小時在前、分鐘在後的直接讀數法。

Example：twelve thirty / four fifteen

Textbook_Note：教材核心時間表達方式。

LF02

Topic：It’s 縮寫

Rule：It’s = It is

Example：It’s twelve o’clock.

Textbook_Note：教材核心問答使用。

LF03

Topic：-teen vs. -ty

Rule：教材延伸頁提醒數字字尾與重音差異。

Example：fifteen vs. fifty

Textbook_Note：屬教材延伸提醒。

老師小提醒

Teaching Analysis

TA01

Topic：非人稱 it

Observation：What time is it? / It’s twelve thirty. 中的 it 指抽象時間。

Example：It’s four fifty.

Teaching_Value：幫助學生避免把 it 直譯為「它」。

TA02

Topic：故事語言觀察

Observation：故事中出現 must + 原形動詞與 Time to + V。

Example：We must go home. / Time to go home.

Teaching_Value：可作理解用，但不應自動升級為核心句型目標。

Extended Patterns

Pattern_1

English：It’s [HOUR] o’clock.

Chinese：現在是……點整。

Function：表達整點時間。

Pattern_2

English：It’s [HOUR] [MINUTE].

Chinese：現在是……點……分。

Function：表達非整點時間。

Pattern_3

English：Time to go home.

Chinese：該回家了。

Function：故事情境中的作息提醒。

Pattern_4

English：We must go home.

Chinese：我們必須回家了。

Function：故事情境中的必要行動。
